A responsive frontend project focused on building a clean, adaptable layout across mobile, tablet, and desktop.

This was one of my first projects where I focused on translating a Figma design into a working interface while making sure it held up across different screen sizes.

👉 Live site: https://jhm323.github.io/se_project_aroundtheus/

---

## What it does

- Displays a profile-based photo gallery with interactive cards  
- Adapts layout from mobile (single column) to desktop (multi-column grid)  
- Handles text overflow and responsive image scaling  
- Includes basic UI interactions like hover states and “like” buttons  

---

## Tech

- HTML (semantic structure)
- CSS (Flexbox, Grid, media queries)
- BEM for styling organization
- Normalize.css for consistency

---

## Approach

- Built mobile-first, then scaled up to larger breakpoints  
- Used CSS Grid for the card layout and Flexbox for alignment  
- Focused on keeping the layout stable across edge cases (long text, different image sizes)  

One thing I paid attention to here was making sure the layout didn’t break when content changed—especially with card sizes and text overflow.

---

## What I learned

- How to structure responsive layouts with Grid and Flexbox  
- How to translate a design system (Figma) into actual code  
- The importance of small details like spacing, alignment, and overflow handling  

---

## What I’d improve

- Add JavaScript for real interactivity (modals, editing profile, etc.)  
- Persist data instead of static content  
- Improve accessibility (ARIA roles, keyboard navigation)
